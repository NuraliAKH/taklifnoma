# Задача 04 — Шаблон «Hilal» (`HilalWeddingSite.tsx`, ID 7, 11, 12, 20–24 — 8 цветовых вариантов)

Прочитай `prompts/templates/00_COMMON_RULES.md` и следуй ему. Используй `frontend/src/templates/sites/shared/`.

## Что сейчас хорошо (сохранить)
Есть собственная идея: исламская арка, Bismillah, аят из суры Ар-Рум 30:21, палитры `HILAL_PALETTES` для вариантов, свой объект переводов, календарь с подсветкой дня, две кнопки карт. Это сильная основа — дорабатываем, а не переделываем с нуля.

## Что плохо
- Класс `font-arabic` используется, но НИГДЕ не определён → арабский текст рендерится системным шрифтом (на Android выглядит грубо). Это главный баг шаблона.
- Аят и Bismillah с `drop-shadow` свечением и `tracking-wide` — для арабской вязи трекинг ломает соединение букв. Убрать `tracking-*` с арабского текста.
- Подарочная карта «glassmorphic» и дефолтный номер `5614 6887 0174 4723`.
- Unsplash фото по умолчанию, 19 мест с текстом < 12px.
- Частицы `HilalParticleSystem` (18 шт. бесконечно) + `GoldBurst` + пульсация печати одновременно.
- Дефолтные имена капсом `DIYORBEK`, `OYSHA` — капс должен быть стилем (`uppercase`), а не данными.
- Нет `aria-*`.

## Арт-дирекшн (усилить, не менять)
Строгая исламская геометрия: изумруд, золото, слоновая кость. Спокойствие, уважение, торжественность.
- Арка: замени текущую арку на точную SVG-форму стрельчатой арки (pointed arch) с двойной золотой линией и маленьким гирих-орнаментом в замке арки. Один компонент `HilalArch`, используется на обложке и для фото.
- Добавь SVG-компонент `GirihPattern` (8-конечная звезда, повторяемый паттерн) — как фон обложки с прозрачностью 4–6%, цвет из палитры.
- Полумесяц (`hilal`) — тонкий SVG в шапке, не эмодзи и не lucide `Moon`.
- Шрифты: `Amiri` (арабский), `Cormorant Garamond` (имена и заголовки), `Montserrat` (текст).

## Аят (секция `quran`)
- `dir="rtl" lang="ar"`, класс `.font-arabic`, 26–30px, `leading-[2]`, без `tracking`, без свечения.
- Перевод на ru/uz/en — проверь, что переводы точные (смысловой перевод Кулиева для ru, Алоуддин Мансур для uz), источник: «Ар-Рум, 30:21» / «Rum surasi, 21-oyat» / «Ar-Rum 30:21».
- Секция скрываемая (как сейчас). Добавь в отчёт рекомендацию в редакторе дать выбор из 2–3 аятов/дуа (не реализуй выбор сам, только напиши).

## Палитры
Пройди все 8 вариантов (`default/emerald`, `sapphire`, `rose`, `champagne-hilal`, `dusty-rose-hilal`, `dusty-blue-hilal`, `navy-hilal`, `burgundy-hilal`): у каждого проверь контраст текста AA на фоне и что золото не превращается в жёлто-оранжевое. Сделай палитру через CSS-переменные на корневом элементе (`--hilal-bg`, `--hilal-accent`, `--hilal-paper`, `--hilal-ink`…), а в JSX — `bg-[var(--hilal-bg)]` и т.п., чтобы не было десятков условных классов.

## Анимации
- Обложка: печать без бесконечной пульсации — лёгкое «дыхание» (scale 1→1.03) не чаще раза в 3 с, максимум.
- Частицы — ≤ 10, только на обложке, выкл. в `useCalmMotion`.
- `GoldBurst` по тапу на печать — оставить.

## Остальное
- Подарки: по общим правилам, без glassmorphism — бумажная карточка с тонкой золотой рамкой, номер `tabular-nums`, кнопка «скопировать» через `useCopyToClipboard`.
- Имена: хранятся как ввёл пользователь, капс — через CSS.
- Добавь «Добавить в календарь» в секцию календаря.

## Сохранить
ID секций: `hero, quran, schedule, countdown, calendar, gallery, venue, rsvp, gift`. Переводы, палитры, менеджер секций, язык, музыку, лайтбокс.

## Критерии
- Арабский текст в Amiri на Android/iOS, без трекинга, читается.
- Все 8 вариантов проверены (в отчёте — таблица: вариант / фон / акцент / контраст текста).
- Отчёт по формату.
