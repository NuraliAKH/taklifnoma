# Задача 05 — Шаблон «Taklifet / Конверт» (`TaklifetPinkSite.tsx`, ID 8, 13–19 — 8 цветовых вариантов)

Прочитай `prompts/templates/00_COMMON_RULES.md` и следуй ему. Используй `frontend/src/templates/sites/shared/`.

## Что сейчас хорошо
Анимация конверта (клапан `rotateX 180`, письмо выезжает вверх), палитры `ENVELOPE_PALETTES`, свой объект переводов, карусель фото, календарь, обе карты. Идея правильная.

## Что плохо
- Базовый цвет конверта — `#7C3AED` / `#8B5CF6` / `#581C87` (фиолетовый Tailwind violet). Это самый узнаваемый цвет «сделано ИИ». Конверт выглядит как пластиковая плашка: `rounded-3xl`, градиент, нет бумаги.
- Секция «Пожелание» (`wish`) содержит захардкоженный узбекский текст «Gulday ochilgan bu baxt kunida...» — не переводится и не редактируется.
- `VENUE` по умолчанию `BAXT TO'YXONASI` капсом в данных, апостроф вместо `ʻ`.
- Дефолтная карта `8600 7710 4420 8911`, Unsplash фото.
- Карусель — только кнопки, нет свайпа пальцем.
- Падающие лепестки `PetalParticleSystem` + `GoldBurst` + пульсирующее свечение печати.
- 17 мест с текстом < 12px, нет aria.

## Арт-дирекшн
Нежный цветочный, «бумажный». Конверт должен выглядеть как настоящий: плотная бумага, тень, фактура.
- Базовая палитра (вариант по умолчанию / ID 8): НЕ фиолетовый. Сделай «лаванда-пыльная» — `#B9A7C9` конверт, `#F6F1F7` бумага, `#4A3A57` текст, золото `#C6A15B`. Остальные варианты (`pink-envelope`, `emerald-envelope`, `champagne-envelope`, `dusty-rose-envelope`, `dusty-blue-envelope`, `navy-envelope`, `burgundy-envelope`) — проверь и приглуши, чтобы они были «пыльными», а не неоновыми.
- Переведи палитру на CSS-переменные (`--env-paper`, `--env-flap`, `--env-pocket`, `--env-ink`, `--env-accent`, `--env-seal`).
- Конверт:
  - углы скругление 6–10px (не 24px), пропорции реального конверта C6 (~ 1.41 : 1);
  - бумага: лёгкая фактура (SVG `feTurbulence` с низкой непрозрачностью) + внутренняя тень по краям;
  - клапан с собственной тенью, которая уменьшается при открытии;
  - внутренняя сторона клапана — другим оттенком (подкладка с мелким цветочным паттерном, SVG);
  - сургучная печать — неровный край (SVG path, не идеальный круг), монограмма без «♡».
- Цветы: нарисуй 1–2 SVG-веточки (лаванда/полевой цветок) линией + лёгкой заливкой, для обложки и разделителей.
- Шрифты: `Cormorant Garamond` + `Montserrat`, Great Vibes только для имён (если используется).

## Секция «Пожелание» (`wish`)
- Текст берётся из `data.wishText` (новое необязательное поле `SiteData`). Если пусто — используется перевод по умолчанию из объекта переводов на всех трёх языках. Подпись «от кого» — как сейчас (`wishFrom`). Отметь в отчёте, что в редактор нужно добавить поле `wishText`.

## Карусель
Свайп пальцем (framer-motion `drag="x"` с `dragConstraints` и порогом), стрелки `aria-label`, точки — кнопки с `aria-current`. Автопрокрутка выключена.

## Анимации
Лепестки ≤ 10, медленные, только после открытия конверта первые 6 секунд, потом останавливаются. Выкл. в `useCalmMotion`.

## Сохранить
ID секций для `envelope`: `hero, couple, gallery, calendar, schedule, countdown, venue, wish, rsvp, giftCard`. Переводы, варианты, менеджер секций, язык, музыку, wish-модалку (`showWishModal`).

## Критерии
- По умолчанию нет ни одного оттенка Tailwind violet/purple.
- Конверт выглядит бумажным на скриншоте 390px.
- Все 8 вариантов проверены (таблица в отчёте).
- Отчёт по формату.
