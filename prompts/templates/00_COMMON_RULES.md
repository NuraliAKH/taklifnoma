# ОБЩИЕ ПРАВИЛА для всех задач по шаблонам Web-Taklifnoma

Прочитай этот файл целиком перед любой задачей по шаблонам. Если правило из задачи противоречит этому файлу — спроси, не угадывай.

## Контекст
Web-Taklifnoma (web-taklifnoma.uz) — сервис электронных приглашений на свадьбы и праздники в Узбекистане. Пользователь выбирает шаблон, в редакторе вводит свои данные, и гости открывают его сайт-приглашение по ссылке с телефона (Telegram/WhatsApp). 90% гостей — смартфоны, многие — недорогие Android, часто родители и бабушки/дедушки.

Шаблоны лежат в `frontend/src/templates/sites/`. Стек: React 19, TypeScript, Tailwind 4, framer-motion, lucide-react.

## Контракт, который НЕЛЬЗЯ ломать
- Компонент получает `WebsiteTemplateProps` из `types.ts`. Не меняй имена и типы существующих props. Новые поля в `SiteData` добавляй только как необязательные (`?`).
- Режимы: `isPreview` (редактор и каталог — рендер внутри маленького контейнера, без `fixed` на весь экран, без блокировки `body`), `isCatalogPreview`, обычный режим (реальный сайт гостя).
- `isOpened` + `onOpenEnvelope` — экран-конверт. `isPlaying` + `onToggleAudio` — музыка.
- `rsvpState` — анкета гостей. Отправку делает ТОЛЬКО `rsvpState.onSubmit`. Успех показываешь ТОЛЬКО когда `rsvpState.isSuccess === true`. Пока `rsvpState.isSubmitting` — кнопка disabled со спиннером. Без `rsvpState` (каталог/превью) форма показывается, но не делает вид, что что-то отправила.
- `hiddenSections` + `onToggleSection` — ID секций должны совпадать с `getTemplateSections()` в `frontend/src/App.tsx` для этого семейства. Не переименовывай ID.
- `onLanguageChange`, языки `ru`, `uz`, `en`.
- Экспорты из `index.ts` и регистр `siteTemplatesRegistry` — не трогать (кроме случаев, когда задача прямо говорит).

## Обязательные правила качества
1. **Никаких фейковых данных на реальном сайте гостя.**
   - Номер карты для подарков: если `data.giftCardNumber` пустой — секция подарков НЕ показывается на реальном сайте. В `isPreview` показывай пример `8600 •••• •••• ••••` с подписью «пример» (на языке шаблона). Удали все дефолтные реальные номера карт вида `8600 7710 ...`.
   - Фото: если пользователь не загрузил фото, на реальном сайте секция с фото скрывается или заменяется красивым типографским/орнаментальным блоком. Стоковые фото с Unsplash (иностранные пары) — удалить совсем. В превью используй локальные заглушки из `/public` (`/olive-editorial-*.webp`, `/wedding_doves.webp`) или орнаментальный плейсхолдер.
   - Имена родителей, история любви, тексты пожеланий — только из `data`. Если поля нет — секция скрыта на реальном сайте, в превью показан пример.
   - Демо-имена в превью — узбекские и одинаковые по смыслу во всех языках (не «Даниил и Анна»).
2. **Все тексты интерфейса — через объект переводов шаблона** (`ru`/`uz`/`en`). Ни одной захардкоженной строки в JSX, включая `aria-label`, `alt`, названия секций в менеджере секций, «Видео-приглашение» и т.п.
3. **Узбекский язык**: правильная латиница с `oʻ` и `gʻ` (символ U+02BB `ʻ`, не апостроф `'` и не `‘`). Естественные фразы, как пишут в настоящих таклифномах, а не дословный перевод с русского.
4. **Типографика для телефона**: никакого текста меньше 12px (удали `text-[6px]`…`text-[11px]` для читаемого текста; минимум `text-xs`, основной текст 15–16px). Для подписей капсом с трекингом — минимум 11px. Контраст текста — WCAG AA (4.5:1).
5. **Арабский текст** (аяты, «Bismillah»): подключи шрифт Amiri из Google Fonts в `frontend/src/index.css` и определи класс `.font-arabic { font-family: 'Amiri', 'Scheherazade New', serif; }`, `dir="rtl"`, `lang="ar"`. Не использовать `Traditional Arabic` (его нет на Android). Аят не анимировать по буквам, не обрезать.
6. **Производительность**:
   - Бесконечные анимации (частицы, пульсация, shimmer) — максимум 1–2 на экран, только `transform`/`opacity`, и все выключаются при `useReducedMotion()` из framer-motion и в `isPreview`.
   - Частицы: не больше 12 элементов на мобильном.
   - Все `<img>`: `loading="lazy"` и `decoding="async"` (кроме первого экрана), `alt` из переводов, явные `width/height` или `aspect-ratio`, чтобы не было CLS.
   - Видео: `preload="metadata"`, без `autoPlay` с звуком.
   - Никаких `backdrop-blur` на больших площадях и на каждой карточке (тормозит на Android) — максимум для плавающих кнопок.
7. **Скролл**: убрать `snap-y snap-mandatory` и `min-h-[100dvh]` на каждой секции — секции разной высоты, естественный ритм. Полноэкранным может быть только первый экран.
8. **Доступность**: кнопки (музыка, язык, закрыть, стрелки карусели, печать конверта) — `<button>` с `aria-label`; лайтбокс закрывается по Esc и кнопкой, фокус возвращается; у полей формы есть `<label>`; область кликов ≥ 44×44 px.
9. **Не выглядеть как ИИ-шаблон**:
   - Не «стопка одинаковых карточек с рамкой и скруглением 2.5rem» друг под другом. Чередуй: полноширинное фото, текст без карточки, асимметрия, разделители-орнаменты, разные фоны секций.
   - Lucide-иконки в кружочке как главный декор (Heart, Crown, Calendar в круге) — заменить на свои SVG-орнаменты/монограммы или убрать.
   - Убрать «♡» между инициалами, пульсирующие сердечки, «лазерные» полосы прогресса.
   - Один дисплейный шрифт + один текстовый на шаблон. Script-шрифт (Great Vibes и т.п.) — только для имён.
10. **Карты**: кнопки «Yandex Maps» и «Google Maps» (обе), адрес с кнопкой «скопировать». Ссылки — `https://yandex.uz/maps/?text=...` и `https://www.google.com/maps/search/?api=1&query=...`, `target="_blank" rel="noopener noreferrer"`.
11. **Дата**: всегда форматируй через `Intl.DateTimeFormat` для выбранного языка (`ru-RU`, `uz-Latn-UZ` с ручным фолбэком названий месяцев на узбекском, `en-GB`). Никаких `2026 . 10 . 10`.
12. **Кнопка «Добавить в календарь»** (если в шаблоне есть секция даты): генерация `.ics` файла на клиенте + ссылка Google Calendar.

## Как работать
1. Сначала прочитай файл шаблона ЦЕЛИКОМ, `types.ts`, `index.ts`, функции `getTemplateFamily`, `getTemplateSections`, `getEditorFieldsForTemplate` в `frontend/src/App.tsx`, и `frontend/src/utils/timer.ts`.
2. Если в задаче сказано использовать `shared/` — используй хелперы из `frontend/src/templates/sites/shared/` (их создаёт задача 00).
3. Меняй только файлы, указанные в задаче. Не трогай другие шаблоны.
4. Не удаляй функциональность (секции, менеджер секций, музыку, язык, RSVP, лайтбокс, варианты цветов `visualVariant`).
5. После работы: `cd frontend && npx tsc -b --noEmit` и `npm run lint` — без новых ошибок. `npm run build` должен проходить.
6. В конце напиши отчёт строго в формате:
   ```
   ## Отчёт
   Файлы изменены: ...
   Что сделано: (по пунктам задачи, отметь [x] / [ ] )
   Что не сделано и почему: ...
   Новые поля SiteData (если есть) и что нужно добавить в редактор: ...
   Как проверить: (какой ID шаблона открыть, что нажать)
   ```
